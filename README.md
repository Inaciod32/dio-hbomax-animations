# HBO Max — Desafio de Animações CSS | DIO

Projeto desenvolvido para o desafio final da Formação CSS da DIO, com o objetivo de reproduzir uma experiência visual inspirada na HBO Max utilizando HTML e CSS.

## Objetivo

Praticar os principais conceitos estudados durante a formação, com destaque para animações, transições, transformações e responsividade.

## Tecnologias

- HTML5
- CSS3

## Recursos utilizados

- HTML semântico
- Flexbox e CSS Grid
- Media Queries
- Variáveis CSS
- `@keyframes`
- `animation`
- `transition`
- `transform`
- `perspective` e efeitos 3D
- Gradientes animados
- Cards com hover
- Layout responsivo
- Preferência de redução de movimento (`prefers-reduced-motion`)

## Páginas

- `index.html` — landing page principal
- `login.html` — tela de entrada

## Estrutura

